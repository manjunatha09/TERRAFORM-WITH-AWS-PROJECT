AWS Stack

Everything
provisioned.

All 9 AWS services defined in Terraform HCL and deployed in one command.

01 🖥️
Amazon EC2
Two compute instances running Nginx web servers behind the load balancer. This is Server 1.
resource "aws_instance" "srv1" {
  ami = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"
}
02 ⚖️
App Load Balancer
Distributes HTTP traffic across both EC2 instances with health check monitoring. Round-robin routing.
03 🔗
Amazon VPC
Virtual Private Cloud isolating the entire infra in a secure 10.0.0.0/16 network.
04 🌐
Public Subnets
Two public subnets in different AZs for high availability.
05 🚪
Internet Gateway
Enables public internet communication through the VPC boundary.
06 🔒
Security Groups
Firewall rules for inbound/outbound EC2 traffic.
07 🪣
Amazon S3
Object storage for static assets, logs, Terraform state.
08 🛣️
Route Tables
Routing rules directing subnet traffic through the IGW.
09 🎯
Target Groups
Routes ALB traffic to registered EC2 targets with health checks.
